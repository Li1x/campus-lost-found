## 1. 测试策略

### 1.1 测试层级

| 层级 | 范围 | 工具 | 覆盖目标 |
|---|---|---|---|
| 单元测试 | Service 层业务逻辑 | JUnit 5 + Mockito | 核心业务方法 |
| 集成测试 | Controller → Service → Mapper | Spring Boot Test + H2 | API 端到端 |
| 前端组件测试 | Vue 组件渲染和交互 | Vitest + Vue Test Utils | 关键组件 |
| 手动测试 | 完整用户流程 | 浏览器手动 | 关键业务流程 |

### 1.2 测试原则

- 按 Skill 要求区分自动化测试结果和手动检查
- 报告实际运行结果，不声称未运行的测试已通过
- 每个 Phase 完成后运行可用的测试和构建命令
